## Stage 2A Completion — Job Documents & PDF Foundation

- document_status enum: added declined, expired, converted
- job_documents: added approver_name, approver_email, approval_ip, approval_comment, decline_reason, declined_by_name, declined_by_email, declined_at, signed_pdf_storage_key

- document_signatures table: id, document_id, org_id, version_number, signer_role, signer_name, signer_email, signature_data, ip_address, signed_at

### Updated Pages

### Key Design Decisions
- Token security: nanoid(32) tokens, SHA-256 hashed in DB, plain token returned to user
- Version snapshots: Auto-incremented from max existing version to avoid conflicts
- Signed PDFs: Generated by modifying blocks with signature image before pdfmake
- Public endpoints use JSON (not superjson) since they're accessed from the review page
- All public endpoints return generic errors to avoid information leakage
- Financial calculations: server-side validation of line items, subtotal, tax, discount, total
